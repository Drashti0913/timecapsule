How it works

Letters to Future Me

  1. Write a title and a message.
  2. Pick the date it should open.
  3. Press Seal letter. The server keeps the message hidden until that date, so not even you can peek early.
  4. Come back when the countdown ends and press Open.
Write a letter

Memory Wall

  1. Post a short memory tagged with a place, year, and season.
  2. Filter the wall to places and times that matter to you.
  3. React to memories and sort by the most loved.
